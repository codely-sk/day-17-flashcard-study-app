# Day 17 — Flashcard Study App 🧠

A Python-based study app that helps users practice questions using flashcards, check their answers, track their accuracy, and review mistakes.

## ✨ Features

- **Randomized Flashcards:** Questions appear in a random order.
- **Answer Checking:** Compares your answer with the correct answer.
- **Score Tracking:** Counts correct and incorrect answers.
- **Accuracy Calculation:** Displays your performance as a percentage.
- **Mistake Review:** Shows the questions you answered incorrectly along with their correct answers.
- **Interactive Menu:** Start a study session or exit the application.
- **Case-Insensitive Checking:** Answers such as `Python` and `python` are treated equally.

## 🛠️ Technologies Used

- Python 3
- `random` module
- Lists and dictionaries
- Functions and loops
- Conditional statements
- String methods

## ▶️ How to Run

1. Make sure Python 3 is installed on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code or a terminal.
4. Run the following command:

```bash
python flashcard_app.py
```

## 📚 How It Works

1. Choose **Start studying** from the menu.
2. Read each question displayed by the application.
3. Press Enter to reveal the correct answer, or type `quit` to end the session.
4. Enter your answer and check whether it is correct.
5. View your final score, accuracy, and incorrect answers.
6. Start another session or exit the application.

## 🎯 Learning Objectives

This project demonstrates how to organize related information using dictionaries, manage collections using lists, shuffle items with Python's `random` module, validate user input, calculate percentages, and build an interactive menu-driven application.
